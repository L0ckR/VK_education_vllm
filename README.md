# VK Education: VLLM-проект

Репозиторий содержит материалы по проекту в рамках VK Education: постановку задачи, план экспериментов, описание используемых датасетов, а также шаблон итогового отчёта.

## Структура

- `docs/project_description.md` — детальное описание проекта: цель, задачи, метрики, датасеты, метод обучения, план экспериментов и формат артефактов.
- `docs/final_report_template.md` — шаблон итогового подробного отчёта по решению.

## Быстрый старт

1. Ознакомьтесь с `docs/project_description.md`.
2. Зафиксируйте baseline и выберите улучшения.
3. Ведите эксперименты по плану и заполняйте отчёт по шаблону `docs/final_report_template.md`.

## Ожидаемые результаты

Проект ориентирован на воспроизводимое обучение/дообучение модели и прозрачную оценку качества по заранее определённым метрикам с публикацией итоговых артефактов (веса, отчёт, таблицы, презентация).
