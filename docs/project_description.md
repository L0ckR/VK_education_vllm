# Описание проекта: дообучение VLM на открытых данных VK

## 1. Цель проекта

Обучить и сравнить русскоязычные Vision-Language модели на открытых наборах VK/DeepVK,
чтобы получить максимальное качество на бенчмарках **GQA-ru** и **MMBench-ru** при разумной
стоимости обучения.

## 2. Задачи проекта

1. Подготовить воспроизводимый ML-каркас (структура, конфиги, скрипты, документация).
2. Задокументировать использование открытых данных VK из коллекции DeepVK VLM.
3. Обучить baseline-конфигурацию LoRA для VLM-модели.
4. Провести оценку по GQA-ru и MMBench-ru.
5. Подготовить итоговые артефакты: описание модели, метрики, отчёт, презентацию.

## 3. Используемые открытые данные VK и как они применяются

Источник: коллекция DeepVK на Hugging Face
`deepvk/vision-language-modeling-664dd7e4c257cc78e740f6bc`.

### 3.1 GQA-ru
- Роль: валидация качества визуального question answering на русском языке.
- Использование в проекте:
  - train/val/test манифесты в `data/gqa_ru/`;
  - конфиг датасета — `configs/data/gqa_ru.yaml`;
  - эксперимент — `configs/experiments/gqa_ru_qwen25vl_lora_v1.yaml`.

### 3.2 MMBench-ru
- Роль: бенчмарк общего мультимодального понимания на русском.
- Использование в проекте:
  - train/val/test манифесты в `data/mmbench_ru/`;
  - конфиг датасета — `configs/data/mmbench_ru.yaml`;
  - эксперимент — `configs/experiments/mmbench_ru_qwen25vl_lora_v1.yaml`.

## 4. Планируемая модель и подход

- База: `Qwen/Qwen2.5-VL-3B-Instruct` (см. `configs/model/base_vlm.yaml`).
- Метод: parameter-efficient дообучение через LoRA (см. `configs/train/lora_ft.yaml`).
- Целевые метрики:
  - GQA-ru: `accuracy`;
  - MMBench-ru: `mmbench_score`;
  - дополнительные: exact_match, macro-F1.

## 5. Ожидаемый результат

1. Обученная VLM-модель (или LoRA-адаптер) с воспроизводимыми конфигами.
2. Таблица сравнения baseline и улучшений на GQA-ru/MMBench-ru.
3. Подробный отчёт (метод, данные, эксперименты, ошибки, ограничения).
4. Дополнительные материалы: презентация и инструкции по запуску.

## 6. Что уже подготовлено в этом репозитории

- Структура проекта под дальнейший запуск на GPU.
