# Правила хранения данных

Эта директория предназначена для датасетов и промежуточных артефактов.

## Структура
- `raw/` — неизменяемые исходные данные из источников.
- `interim/` — промежуточные данные после этапов предобработки.
- `processed/` — финальные очищенные/подготовленные данные для обучения и анализа.
- `external/` — внешние данные из сторонних источников.

## Правила
1. **Не коммитьте большие файлы** в Git.
2. В репозитории храните только лёгкие примеры, схемы и метаданные.
3. Тяжёлые датасеты храните во внешнем хранилище (S3/MinIO/NAS/DVC/LFS и т.п.).
4. При необходимости добавляйте скрипты в `scripts/` для скачивания или воспроизведения данных.
5. Не храните секреты и персональные чувствительные данные.

## Рекомендуемая практика
- Для каждого набора данных фиксируйте источник, версию и дату обновления.
- Используйте понятные имена и суффиксы с датой/версией.
